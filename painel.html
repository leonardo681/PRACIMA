Conectar ao GitHub (só na primeira vez)

A chave do GitHub é o que realmente protege o site: sem ela, ninguém altera nada. Siga os passos:

  1. Entre no GitHub com a conta leonardo681 (a dona do repositório). Uma chave criada em outra conta não funciona, mesmo que essa conta seja colaboradora.
  2. Ative a verificação em duas etapas (2FA) e guarde os códigos de recuperação.
  3. Abra a página de criar a chave: Criar a chave no GitHub.
    Se o link não funcionar: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  4. Configure a chave:
    • em “Repository access”, escolha Only select repositories → PRACIMA;
    • em permissões, Contents: Read and write (Metadata fica só leitura, automaticamente);
    • validade de 1 ano.
  5. Clique em “Generate token”, copie a chave (começa com github_pat_) e cole abaixo. Se perder, não tem problema: é só criar outra e apagar a antiga.

Marque só no seu celular pessoal, com bloqueio de tela.

Publicar sem a chave

Gera o arquivo produtos.json com todas as alterações, para colar no GitHub à mão.

Nova categoria

    Uma categoria só pode ser excluída quando não tem nenhum produto, nem oculto. Para esvaziar, edite os produtos e troque a categoria deles.

    Estas informações aparecem na parte da igreja e na faixa do topo do site. Campo vazio não aparece no site. As mudanças vão junto no próximo “Publicar”.

    Como funciona

    Tudo o que você muda aqui fica guardado só neste aparelho (é o “rascunho”) até você tocar em Publicar. A barra embaixo mostra quantas alterações ainda não foram publicadas. Pode fechar o painel sem medo: o rascunho continua guardado.

    Adicionar um produto

    1. Na aba Produtos, toque em + Novo produto.
    2. Preencha o nome, a categoria e o preço. O preço pode ser digitado como 74 ou 74,50.
    3. Se quiser, escreva a descrição, uma informação curta (ex.: “Tamanhos P ao GG”) e as variações com preço próprio (ex.: Adulto e Infantil).
    4. Para a foto, toque em Escolher foto: dá para tirar na hora ou pegar da galeria. O painel já diminui a foto sozinho.
    5. Marque Novidade para o produto ganhar o selo por 30 dias.
    6. Toque em Salvar e depois em Publicar.

    Ocultar ou excluir

    • Ocultar (chave Visível / Oculto): o produto some do site, mas continua guardado. Para voltar, é só deixar Visível de novo. Use quando acabar o estoque ou o produto sair por um tempo.
    • Excluir: apaga o produto de vez. Só use quando ele não vai mais voltar.
    • Duplicar: cria uma cópia (sem foto) para cadastrar um produto parecido mais rápido.
    • As setas ↑ ↓ mudam a ordem dos produtos dentro da categoria.

    Publicar

    1. Toque em Publicar na barra de baixo.
    2. Confira a lista de alterações e os avisos, e confirme.
    3. Espere a mensagem “Enviado!”. Não feche o painel enquanto estiver enviando.

    Quanto tempo demora? Normalmente o site atualiza para todos em 1 a 2 minutos, mas pode levar até 10. O painel avisa quando já estiver no ar. Se depois de 12 minutos ainda não tiver aparecido, abra github.com/leonardo681/PRACIMA/actions para ver se deu erro.

    Se outra pessoa publicar ao mesmo tempo, o painel junta as duas coisas: as suas alterações são aplicadas por cima da versão mais nova, sem apagar o que a outra pessoa fez.

    Sem a chave (só rascunho)

    Dá para preparar tudo e tocar em Baixar produtos.json. Depois, no GitHub: abra o repositório PRACIMA → pasta data → produtos.json → lápis (editar) → apague tudo e cole o conteúdo novo → Commit changes. Isso substitui o arquivo inteiro. Fotos só podem ser enviadas com a chave.

    A chave expirou ou se perdeu

    A chave vale por 1 ano. Quando ela expirar, o painel avisa “Chave do GitHub inválida ou expirada” e pede outra. Nada do rascunho se perde.

    1. Entre no GitHub com a conta leonardo681.
    2. Abra a lista de chaves e apague a antiga (se ainda aparecer).
    3. Crie uma nova pelo passo a passo da tela “Conectar ao GitHub” (criar a chave): Only select repositories → PRACIMA, Contents: Read and write, validade de 1 ano.
    4. Cole a chave nova no painel.

    Perdeu o celular onde a chave estava lembrada? Apague a chave na lista de chaves do GitHub na hora. Sem ela, ninguém consegue alterar o site.

    Segurança

    • O login deste painel é só uma cortina para curiosos. Como o site é estático e o código é público, quem ler o código consegue passar desta tela.
    • Quem protege de verdade é a chave do GitHub. Sem ela, ninguém altera nada, mesmo passando do login.
    • A chave nunca vai para o repositório: nem codificada, nem criptografada, nem dividida em partes. O GitHub revoga sozinho chaves que aparecem em repositório público.
    • O endereço leonardo681.github.io é dividido com os outros sites dessa conta no GitHub Pages, e todos eles conseguem ler o que fica guardado no navegador para esse endereço. Por isso, o padrão é guardar a chave só até fechar o navegador.
    • Marque “Lembrar neste aparelho” só em celular pessoal com bloqueio de tela. Para isolar de vez, dá para usar um domínio próprio ou uma conta/organização separada no GitHub (ex.: sarabiguacu.github.io).
    • Sair apaga só o login desta sessão (e a chave, se ela não estiver lembrada). O rascunho continua guardado.

    Se algo der errado:

    1. apague (revogue) a chave em github.com/settings/personal-access-tokens;
    2. volte o commit no GitHub (revert). Todo o histórico fica salvo.
